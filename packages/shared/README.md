# @ghotok/shared

Code that must mean the same thing in the API, the website and the admin panel. No dependencies; runs in Node and the browser.

| Module                       | Contents                                                                                       |
| ---------------------------- | ---------------------------------------------------------------------------------------------- |
| `src/biodata/schema.js`      | **The biodata definition** — sections, fields, labels, conditions                              |
| `src/biodata/rules.js`       | Input sanitising, submission rules, legal age, public projection, codes                        |
| `src/options.js`             | Option lists (religions, professions…), locations, roles                                       |
| `src/format.js`              | Bangla digits, money, heights, dates, labels, addresses                                        |
| `src/phone.js`               | Bangladeshi mobile and wallet (Rocket) number normalising                                      |
| `src/i18n/errors.js`         | Bilingual API error and field messages                                                         |
| `src/i18n/labels.js`         | Bilingual workflow status labels                                                               |
| `src/generated/locations.js` | Generated by `npm run geo:build` from `data/geo` (MIT, nuhil/bangladesh-geocode) — do not edit |
